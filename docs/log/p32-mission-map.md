## 지시

### 목표

미션 맵(ARCH 4절 I6, `Mission.jsx`, `M` 키)을 읽기 쉽고 보기 좋게 다시 만든다. 사용자의 말은 다음과 같다.
- "mission map 가독성 및 디자인 개선 요청."
- "mission map에서 아무것도 없는 창 누르면 닫히게 해 줘."
- "'열린 세션 수' 보여 주는 버튼 누르면 mission map으로 이동."
- "어케 할지는 난 잘 모르겠다. 너가 잘 해봐."

### 할 것

1. **디자인과 가독성.** 지금 미션 맵을 개발용 판에 세션 여럿(사람 → 리드 → 작업자 둘, 리뷰어 하나, 하위 세션 하나, 연결 없는 세션 하나, 내 차례 세션 하나)을 놓고 찍어 본 뒤, 무엇이 읽기 어려운지 작업 기록에 적고 다시 짠다. 방향은 네가 정한다. 다음을 참고한다.
   - 한눈에 보여야 할 것: 누가 누구에게 시키는지(방향과 역할), 지금 일하는 곳, 내 답이 필요한 곳.
   - 세션 상태 색, 종류 아이콘(Claude 심볼 등), 이름표는 판의 노드·칩과 같은 말과 색을 쓴다(`tokens.css`의 변수만, 초록 강조색, 내 차례는 주황).
   - 글은 짧게, 크기 위계를 분명히. 긴 지시·답은 줄여 보이고 마우스를 올리면 더 보인다.
   - 선이 겹치거나 상자가 겹치지 않게 놓는다. 세션이 많아도(15개 이상) 무너지지 않게 한다.
   - 맵 안의 세션을 누르면 지금처럼 그 노드로 간다(맵은 닫힌다).
   - 영어·한국어 화면 모두 본다.
2. **빈 곳을 누르면 닫힘.** 맵 안의 상자·선·단추가 아닌 빈 곳을 누르면 닫힌다. Esc는 지금처럼 닫는다.
3. **세션 수 알약 → 미션 맵.** 오른쪽 위 연결 상태 알약(초록 점과 "N sessions", `Chrome.jsx`의 `data-role="conn"`)을 누르면 미션 맵이 열린다(열려 있으면 닫힌다). 백엔드나 herdr가 끊겨 다른 글이 보일 때의 동작은 네가 정한다. 마우스를 올리면 지금처럼 연결 상태 풀이가 보인다.

- `items.js`의 옛 두 열 배치(`missionLayout`, `MISSION`)는 뺐다.

### 계획과 다른 곳

- 백엔드 `mission.mjs`는 고치지 않았다. 그래프의 `column`, `directs`는 화면 배치에 더는 쓰지 않는다(`atrium mission` CLI 출력에는 남아 있다).
- 형제 순서를 분류 순에서 이름 순으로 바꿨다(연 동안 자리가 바뀌지 않게).
- 덮개에 `backdrop-filter: blur(6px)`를 더했다.
- 옛 미션 맵 e2e 셋은 선택자만 고치고 다시 돌리지는 않았다(각자 그 단계의 판 차림이 필요하다). `p6c-i67`은 선 글을 `<text>` 대신 선의 `<title>`에서 읽고, `p22-remove`는 열 머리 수 대신 그룹 노드·소속 선이 없는지만 보고, `p8-k4`는 들여 쓰기 표시 대신 상자 `title` 첫 줄(`@이름 · 역할`)을 남긴다.

### 알려진 문제

- 나무 밖 선이 여러 열을 건너뛰면 가운데 열의 상자 뒤로 지나간다(상자가 위에 그려져 선이 가려진다). 이름표가 없고 점과 올림 풀이만 있다.
- 받는 상자 하나에 지시자가 넷 이상이면 넷째부터는 이름표 없이 가운데 끝으로 모인다.
- 상자를 눌러 간 노드는 화면 가운데로 오지만 고름(selected)은 바뀌지 않는다(옛 동작과 같다, `navigateTo`).
- `p6c-i67.mjs`의 `[data-action="mission-open"]`은 지금 창에 없는 이름이다(아래 칩은 `chip-mission`). 이 작업 전부터 그랬고 고치지 않았다.
