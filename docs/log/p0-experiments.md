## 지시

### 지휘 세션이 정한 범위(옛 `docs/PLAN.md` 7절 P0)

실험은 모두 CLI에서 새로 띄운 `claude` 세션으로, 시험용 폴더에서 한다. herdr 실험은 이름 있는 별도 herdr 세션에서 하고 끝나면 지운다. 데스크톱 앱 세션, 사용자의 기본 herdr 세션, 기존 세션은 쓰지 않는다. 결과는 `docs/experiments/`에 하나씩 남긴다. 시험 프로젝트 폴더는 신뢰된 폴더 아래에 두되, 따로 git 저장소로 만들지 않는다. 따로 `git init`하면 신뢰 대화상자가 뜨고, 신뢰는 누르지 않으므로 시험을 할 수 없다(P1).

## 작업 기록

실험 하나가 `docs/experiments/E<번호>.md` 하나다. 날짜, 방법, 측정값, 해석이 거기에 있다.

## 보고

### 실험별 결과(옛 `docs/PLAN.md` 7절 P0 표)

| 번호 | 확인할 것 | 상태 |
|---|---|---|
| E0 | herdr API로 세션 시작, 상태 이벤트, 화면 실시간, 글 보내기 | 끝남. 네 가지 모두 됨 |
| E1 | node-pty로 `claude.exe` 띄우기, 입력, 제출 | 끝남. 됨. herdr 구조에서는 참고 자료 |
| E2 | `--settings`의 http hook 도착, 상세, 지연, 수신기 장애 | 끝남. 됨. SessionStart는 http hook을 부르지 않음 |
| E3 | 여러 줄, 수 KB 글을 `agent.prompt`와 `pane.send_input`으로 넣었을 때 그대로 제출되는가(한글 한 줄은 E0에서 됨) | 끝남. 됨(100KB까지 한 턴). hook `prompt`는 `<pasted_content>`로 감싸질 수 있음 |
| E4 | 제어기 프레임을 xterm.js에 넣었을 때 Claude Code 화면(전체 화면 렌더러 포함)이 제대로 그려지는가 | 끝남. 됨. 조건: unicode11, 붙여넣기 감싸기, 휠 변환, 전체 화면 렌더러 |
| E5 | 가까이 보이는 노드 8개에 제어기를 붙였을 때 메모리, CPU, 화면 지연 | 끝남(P2 창으로). 제어기 8개 127MB, 창 약 420MB, 50ms 넘는 프레임 0. WebGL 예산 8과 제어기 상한 8을 기본값으로 |
| E6 | xterm.js 안에서 한글 입력(IME)이 제대로 되는가(작은 시험 창 필요) | 자동화한 부분은 됨(조합 중 보내지 않음, 음절마다 한 번, 배율과 무관). 실제 IME 점검표(`docs/experiments/E6.md` 4절)는 사용자 확인 대기 |
| E7 | herdr 서버를 다시 시작하거나 강제 종료하면 claude 세션과 hook 설정이 어떻게 되는가 | 끝남. claude도 함께 끝나고 다시 띄우면 이어 감. hook을 지키려면 `resume_argv` 등록과 토큰을 설정 파일에 두기가 필요 |
| E8 | SQLite를 Node 24 내장 모듈로 쓸지, 별도 패키지로 쓸지 | 끝남. `node:sqlite`를 쓴다. 실험 단계 모듈이라 저장소 모듈 안에 가둔다 |
| E9 | 권한 요청과 질문의 각 선택지에 `agent.send_keys`로 답할 수 있는가. 답한 뒤 어떤 hook이 오는가 | 끝남. 모든 선택지 됨. 거부와 취소에는 hook이 없음 |
| E10 | 처음 쓰는 폴더의 신뢰 대화상자에서 herdr 상태는 무엇인가. `~/.claude.json`으로 미리 알 수 있는가 | 끝남. `blocked`(권한 요청과 같음, hook 없음과 `launch_pending`으로 구분). 상위 폴더까지 보면 예상됨 |
