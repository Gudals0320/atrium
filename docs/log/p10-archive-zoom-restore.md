## 지시

### 목표

사용자가 실제 판을 써 보고 준 피드백 네 가지를 고친다. (1) 판 밖 Claude Code 대화를 전부 불러와 쌓일수록 무거워진다 → 보관(아카이브). (2) 붙여 묶은 노드를 눌러 들어가면 그 노드 하나만 보인다 → 덩어리 전체. (3) 많이 줄이면 노드 안 글이 억지로 끼워져 깨진다 → 아주 멀리서는 종류 아이콘만. (4) 새로 연 판이 비어 있었고, 열었던 Claude Code CLI 세션이 돌아오지 않았다 → 판이 사용자의 리포와 CLI 대화를 스스로 찾아 다시 보인다.

(4)의 배경: 이번에는 재부팅이 없었다(부팅 10:26). 사용자는 바탕화면 바로가기로 실제 판(`multitask`, 47800)을 처음 열었고, 그 판은 15:03에 새로 만들어져 비어 있었다. 그 전의 세션은 개발용 판(`multitask-dev`)에 있다. 또 지금 판 밖 대화 목록은 이미 열린 워크스페이스에 대해서만 보이므로, 새 판에는 아무것도 보이지 않는다.

### 시나리오

1. **보관(아카이브).** 판 밖 대화와 닫힌 세션을 "보관"으로 뺄 수 있다. 보관은 지우기가 아니다. 대화 기록 파일과 판 기록은 그대로 둔다.
   - 보관된 것은 기본으로 불러오지 않는다: 사이드바의 기본 목록, 검색, 창으로 보내는 목록에서 빠진다. 대화 기록 색인(`convo_index`)도 보관된 대화의 글을 다시 읽지 않는다.
   - 손으로: 사이드바 줄의 "보관", 리포 묶음의 "오래된 것 보관".
   - 저절로: 마지막 활동이 일정 기간(설정, 기본 14일)보다 오래된 판 밖 대화와 닫힌 세션은 보관으로 본다. ⚙에서 기간을 바꾸거나 끈다.
   - 사이드바에 "보관함"(접혀 있음)이 있어 보관된 것을 리포별로 찾고 거르고 "꺼내기"로 되돌린다. 꺼낸 것은 다시 기본 목록에 나오고, 저절로 보관 기간에 다시 걸리지 않게 한다(꺼낸 뒤의 활동 시각부터 센다).
   - 판에 열려 있는 세션은 보관할 수 없다(먼저 끈다). P7의 "빼기"(`recall.dismiss`)는 보관으로 합친다.
2. **붙은 노드로 들어가기.** 덩어리(붙여 묶기, ARCH 4절 H5) 안의 노드를 누르거나, 칩·검색·사이드바·알림으로 그 노드에 가면, 덩어리 전체가 한 화면에 들어오게 맞춘다. 초점과 터미널 입력은 누른 노드로 간다. 덩어리가 커서 다 들어오면 가까이 얼굴이 안 되는 경우의 처리(덩어리 전체를 우선할지, 누른 노드를 가까이 얼굴로 둘지)는 써 보고 정하고 보고에 적는다. 지금 화면 이동은 `app/src/renderer/Canvas.jsx`의 `navigateTo`, `navigateToRect`다.
3. **아주 멀리서는 아이콘만.** 노드가 화면에서 아주 작으면(예: 너비 140px 아래, 기준은 정해서 적는다) 노드 안에 글을 넣지 않고 에이전트 종류 아이콘 하나(Claude Code, Codex, Pi, 셸, 그 밖)와 상태 색(테두리나 점)만 그린다. 기다리는 노드는 지금처럼 눈에 띄게 한다(깜빡이는 테두리, 화면 기준 말풍선은 지금 동작을 지키되 글이 깨지지 않게). 지금보다 덜 줄였을 때의 멀리 얼굴(`SessionNode.jsx` `FarFace`)도 글이 넘치지 않게 줄이거나 자른다. 아이콘은 웹에서 받은 상표 로고 파일을 넣지 말고, 종류마다 직접 그린 단순한 기호(모양, 색, 머리글자)로 한다. 나중에 사용자가 로고 파일을 넣을 수 있게 아이콘을 한곳(예: `app/src/renderer/lib/kinds.js`)에 모은다.
4. **판이 리포와 CLI 대화를 스스로 찾는다.**
   - 판의 워크스페이스, 노드 자리, 열린 세션이 창·백엔드·herdr를 끄고 켜도 그대로인 것을 다시 확인하고 시험으로 남긴다(ARCH 4절 J1이 이미 한다). 실제 PC 재부팅은 사람이 확인한다.
   - 판이 사용자가 Claude Code CLI(터미널)로 일한 리포를 찾아 워크스페이스로 저절로 연다. 기준: 보관 기간 안에 활동한 대화 중 대화 기록 안의 출처가 CLI인 것(`entrypoint`, ARCH 4절 J4). 데스크톱 앱 출처만 있는 리포는 저절로 열지 않는다. 사용자가 닫은 워크스페이스는 다시 저절로 열지 않는다(기억한다). 새 판이 비어 있어도 처음 켤 때 이렇게 채워지고, 사이드바에 그 리포들의 대화가 보인다. 이 동작은 ⚙에서 끌 수 있다.
   - 다른 판(예: 개발용 판)의 claude가 지금 열고 있는 대화는 P7 규칙대로 "터미널 · pid n"으로 묶여 보인다. 그 세션을 끄면 이 판에서 같은 대화로 이어 갈 수 있다. 판끼리 세션을 옮기는 도구는 만들지 않는다.
   - 저절로 연 워크스페이스는 캔버스에 영역만 두고 노드는 띄우지 않는다(세션을 저절로 띄우지 않는다. 토큰을 쓴다). 빈 영역이 캔버스를 너무 차지하지 않게 작게 둔다.

### 완료 기준

1. 판 밖 대화와 닫힌 세션을 손으로 보관하고, 보관함에서 찾아 꺼낼 수 있다. 기간이 지난 것은 기본 목록·검색에 나오지 않는다. 대화 기록 파일과 판 기록은 지워지지 않는다(단위 시험과 창 스크린숏).
2. 덩어리 안의 노드로 가면 덩어리 전체가 화면에 들어오고 초점은 그 노드에 있다(창 시험).
3. 아주 멀리서 노드가 종류 아이콘과 상태 색만 보이고 글이 깨지지 않는다. 기다리는 노드는 그래도 눈에 띈다(스크린숏을 배율 여럿으로).
4. 빈 판을 처음 켜면 CLI 대화가 있는 시험 폴더가 워크스페이스로 열리고 그 대화가 사이드바에 보인다. 데스크톱 출처만 있는 폴더(고정 자료)는 열리지 않는다. 사용자가 닫은 워크스페이스는 다시 켜도 열리지 않는다. 판을 끄고 켜도 워크스페이스와 세션이 그대로다.

### 만든 것

### 계획과 다른 곳

1. "오래된 것 보관"의 기준을 마지막 활동 하루로 정했다(`archive.old`의 `days`로 바꿈). 꺼낸 것은 꺼낸 시각부터 세므로, 방금 꺼낸 것은 걸리지 않는다.
2. 큰 덩어리는 누른 노드를 가까이 얼굴로 둔다(만든 것 2).
3. 지시에 없던 것을 더했다: 리포 스스로 찾기가 홈·드라이브 루트·임시 폴더를 열지 않는다(그 아래 대화가 모두 한 워크스페이스로 묶여서). 지금 다른 곳에서 열린 대화는 저절로 보관하지 않는다.
4. 보관된 판 밖 대화의 글은 보관함을 볼 때에만 채운다. 그 전에는 보관함 줄이 대화 ID로 보일 수 있다. 채운 뒤에는 다시 읽지 않는다.
5. 설정이 없는 판(단위 시험의 가짜 백엔드)은 저절로 보관과 찾기를 끈 것으로 본다. P7 시험의 고정 날짜 대화가 시간이 지나도 보관되지 않게 하기 위해서다.
6. 지시 밖의 고침: `recall.changed()` 경합, 덩어리 첫 노드 끄기 오류(작업 기록).

### 알려진 문제

1. **실제 PC 재부팅은 확인하지 않았다.** 창·herdr·백엔드를 차례로 끄고 켜는 것만 했다. 사람이 확인한다.
2. **실제 판에서의 찾기는 사람이 본다.** 시험 판은 고정 자료와 새로 만든 대화만 읽었다. 실제 판에서는 위 판정대로 저장소 3개가 처음 켤 때 열릴 것이다. 열린 것이 맞는지, 520×200 빈 영역이 알맞은지 본다. 원치 않는 리포는 닫으면 다시 열리지 않는다.
3. **판이 띄운 세션의 대화도 cli 출처다.** 다른 판(예: 개발용 판)의 세션이 일한 폴더도 저절로 열린다. 그 폴더가 지워지면 열리지 않는다.
4. 작은 빈 영역은 멀리서 이름표 글자가 커지면 이름이 잘린다(`p10-3-zoom-0_24`의 `mtask-p10-l…`).
5. 아이콘 얼굴의 기다리는 노드 말풍선(220px)은 이웃 노드 위를 덮을 수 있다.
6. 보관함은 리포마다 30개(거르기 중 100개)까지 보이고 나머지는 수만 보인다. 백엔드는 리포마다 300개까지 준다.
7. Codex·Pi·그 밖 종류의 아이콘은 창에서 직접 보지 않았다. 단위 시험과 `kinds.js` 값으로만 확인했다(이 시험은 claude와 셸만 띄웠다).
8. **시험이 남긴 것.** 시험 claude 둘(판 밖 `o1`, 판 `w1`, 두 번)의 대화 기록이 `~/.claude/projects/C--Workspace-mtask-p10-cli`, `-live` 아래에 남았다(읽기만 하라는 규칙에 따라 지우지 않았다). `backend/.dev/`(이 판의 데이터, 창 프로필)는 git이 무시한다. 시험 폴더 `C:\Workspace\mtask-p10-*` 다섯, 고정 자료, herdr 세션 `multitask-dev-p10`·`multitask-dev-p10-outside`는 지웠다. 포트 47822·47823에 듣는 프로세스는 없다. 시험 claude가 `~/.claude.json`에 프로젝트 항목을 남겼을 수 있다.
