## 지시

### 목표

아래 명령 바가 더 쉽게 나오고 부드럽게 올라오게 하고, ↑로 여는 찾기 창을 다시 그린다. 사용자의 말: "하단 바에 마우스 올릴 때 명령 입력줄 뜨는게 너무 범위가 좁아 좀 근처가면 알아서 나오게 해주고 명령줄 나올때 하단에서 올라오는 애니메이션 만들어줘", "방향키 위 누르면 나오는 찾기 대화창 UI가 못생겼는데 개선좀 해주고 이것도 위에서 내려오게 해줘 가볍게. 그리고 크기 좀만 더 키워".

P43이 만든 동작(평소 숨김, 초점이나 쓰다 만 글이 있으면 숨지 않음, 판 화살표 키, 찾기는 바깥을 누르면 닫힘)은 그대로 둔다.

### 할 것

1. **명령 바가 나오는 범위.** 지금은 아래 가장자리의 좁은 띠(`app/src/renderer/lib/bottom.js`의 `inBand`, `BAND_PX`·`BAND_SIDE_PX`)에 마우스가 들어와야 나온다.
   - 아래쪽에 가까이 가기만 해도 나오게 넓힌다. 높이는 명령 바와 칩 줄 높이에 여유를 더한 정도, 가로는 명령 바 폭보다 넉넉히 잡는다. 값은 써 보고 정해 작업 기록에 적는다.
   - 나온 뒤에는 더 넓은 범위를 벗어나야 숨긴다(들어가는 선과 나가는 선을 달리 둠). 숨기기는 약간 늦춰 깜빡이지 않게 한다.
   - 노드 터미널 위에서 아래로 스크롤하거나 글을 고를 때 방해되지 않는지 본다. 노드가 아래쪽에 있을 때도 써 본다.
2. **올라오는 움직임.** 명령 바와 칩 줄이 나올 때 아래에서 살짝 올라오며(위치와 투명도) 나타나고, 숨을 때는 반대로 내려간다. ↓ 키나 초점으로 나올 때도 같다.
3. **찾기 창 다시 그리기(↑).**
   - 조금 더 크게 한다: 폭과 입력칸 높이와 글자를 키운다.
   - 입력칸 앞에 찾기 아이콘을 둔다. 자리 표시 글은 짧게 한다(예: "세션, 대화, 메모 찾기"). 지금의 긴 글에 든 찾는 범위와 키 안내는 따로 보인다. 키 안내는 작은 키 모양(↑↓ 고르기, Enter 이동, Esc 닫기)으로 창 아래나 오른쪽에 둔다.
   - 결과는 종류별 표시(세션, 대화, 메모, 칸반 등), 고른 줄 강조, 맞는 글자 강조, 빈 결과 안내를 다듬는다.
   - 위에서 가볍게 내려오며(위치와 투명도) 나타나고, 닫힐 때는 반대로 움직인다.
4. Electron 창과 웹 화면 둘 다에서 같다.

### 완료 기준

1. 단위 시험을 더하고 통과한다: 넓힌 범위와 들어가는·나가는 선(`inBand`류 순수 함수), 숨김 늦추기.
2. 창 시험(개발용 판, Electron)으로 확인하고 결과를 `experiments/p61/`에 둔다.
   - 아래쪽 가까이에 마우스를 두면 명령 바가 나오고, 멀어지면 늦게 숨는다.
   - 쓰다 만 글과 초점이 있으면 숨지 않는다.
   - 올라오는 움직임과 찾기 창의 내려오는 움직임이 있다. 중간 프레임 스크린숏이나 계산된 transform으로 보인다.
   - `prefers-reduced-motion`이면 움직임이 없다.
   - 찾기 창 전후 스크린숏(두 화면 크기, 결과가 있을 때와 없을 때)을 남기고, ↑·↓·Enter·Esc와 바깥 누르기가 그대로 된다.
3. `cd backend && npm test`, `cd app && npm test`, `cd app && npm run build`가 통과한다.

### 만든 것

- **명령 바가 나오는 범위**(`app/src/renderer/lib/bottom.js`, `CommandBar.jsx` `useAutoHide`)
  - 판 아래 끝에서 150px 위까지, 명령 바 양옆 80px까지 마우스가 오면 110ms 뒤 나타난다(옛 띠는 28px·48px, 90ms).
  - 나온 뒤에는 210px 위, 양옆 150px 범위를 벗어나야 하고, 벗어난 뒤 700ms가 지나야 숨는다(옛 650ms). 그 안에 돌아오면 숨지 않는다.
  - 숨은 동안 마우스 단추를 누른 채 범위에 들어오면 띄우지 않는다.
  - 순수 함수 `bandZone(p, rect, shown)`을 더했다. `inBand`는 그대로이고 상수 값만 바꿨다.
  - P43의 붙잡는 까닭(초점, 쓰다 만 글, 대상 후보·Thread, 칩 줄 초점, 시험 고정)은 그대로다.
- **올라오는 움직임**(`styles.css` 끝)
  - 명령 바: 28px 아래·98.5% 크기에서 0.2초 동안 올라오며 나타나고, 숨을 때 0.15초 동안 내려가며 흐려진다.
  - 칩 줄: 30ms 늦게 같은 거리로 올라오고, 숨을 때는 함께 내려간다.
  - ↓ 키, Ctrl+K, 초점으로 나타날 때도 같다. `prefers-reduced-motion`이면 움직이지 않는다.
- **찾기 창**(`Search.jsx` `SearchBox`, `lib/search-ui.js`, `styles.css` 끝, 두 사전 끝 `searchBox`)
  - 폭 880px까지(옛 760px), 위 62px. 입력칸은 높이 50px, 글자 16px이고 앞에 찾기 아이콘, 글이 있으면 뒤에 지우기 단추가 있다.
  - 자리 표시 글은 "세션, 대화, 메모 찾기"다. 빈 칸일 때 아래에 찾는 범위를 한 줄로 보인다.
  - 아래 줄에 키 안내(↑↓ 선택, Enter 이동, Esc 닫기)가 작은 키 모양으로 있고, 오른쪽에 결과 수가 있다.
  - 결과는 두 줄이다. 왼쪽에 종류 아이콘(세션, 프로젝트, 메모, 칸반), 첫 줄에 이름·상태·종류 표시, 둘째 줄에 맞은 곳의 이름과 글이 있다.
  - 종류 표시와 같은 필드 이름이나 이름과 같은 글은 한 번만 보인다.
  - 고른 줄은 바탕과 왼쪽 초록 줄로 강조하고 ↵ 표시가 붙는다. 위아래 키로 고르면 목록이 그 줄까지 굴러간다.
  - 맞는 글자는 낱말마다(빈칸으로 나눈 말 각각) 이름과 글 모두에서 강조한다.
  - 결과 없음: 아이콘, "“…”에 맞는 결과가 없습니다", 보드 기록만 찾는다는 안내. 결과를 기다리는 동안에는 보이지 않는다.
  - 열릴 때 위 14px에서 0.18초 동안 내려오며 나타나고, 닫힐 때 0.15초 동안 위로 10px 올라가며 흐려진다. 움직임 줄이기면 바로 열리고 닫힌다.
  - ↑·↓·Enter·Esc, 바깥 누르기로 닫기, 안 누르기는 P43 그대로다.

### 알려진 문제

- 들어오는 범위가 넓어져, 노드 터미널의 아래쪽 줄이 판 아래 150px 안에 있으면 그 위에 마우스를 둘 때 110ms 뒤 바가 나타난다. 그 줄이 명령 바 자리(아래 26~86px)나 칩 줄 자리(아래 104~130px)에 있으면 가려져 눌리지 않는다. 화면을 조금 올리면 된다. 바와 칩 사이와 그 위의 줄은 바가 보여도 눌리고 굴러간다.
- 숨은 동안 마우스 단추를 누른 채 범위에 들어와 거기서 놓으면, 마우스를 다시 움직여야 나타난다.
- 시험 판에 띄우지 않은 셸 세션 `sh-w1p1`이 생겨 있었다. 정리 때 껐다. 어디서 생겼는지는 보지 않았다.
