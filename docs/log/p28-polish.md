## 지시

### 목표

화면 몇 곳을 다듬는다. 사용자의 말은 다음과 같다.
- 처음 화면(로딩)은 최소 2초로 고정한다. 아이콘 없이 텍스트 로고만, 더 크게, 아래부터 불이 들어오는 애니메이션으로 보인다.
- 멀리서(줌 아웃) 흐리게 보이는 노드 얼굴이 흐리멍텅하고 디자인이 별로다.
- 캔버스 바탕을 검정에 더 가깝게 한다. 캔버스만이다. CLI(콘솔)는 살짝 톤을 낮춘다.
- 맨 아래 명령 입력이 양옆으로 너무 짧다.
- Delete를 누르고 한 번 더 누르면, 닫기 확인에서 "삭제"를 고르게 한다.
- 설정 창 가독성이 개박살났다. 설정 창에 스크롤이 있으면 안 된다. 미리 탭을 나누어 분류한다. 설정 창 아래 텍스트 로고는 뺀다.

### 정한 것

- **처음 화면.**
  - 판을 받는 것이 빨라도 처음 화면은 최소 2초 보인다. 그 사이 판은 뒤에서 읽는다.
  - 로고 아이콘은 빼고 텍스트 로고(`assets/brand/atrium-wordmark.png`, 원본 `app/design/brand`)만 지금보다 크게(예: 화면 너비의 30~40%) 가운데에 둔다.
  - 아래에서 위로 불이 들어오는 애니메이션: 어두운 글자 위로 밝은 글자가 아래부터 차오른다. 마스크나 clip-path로 2초 안에 한 번, 점 무늬 글자에 어울리게 한다.
  - 연결 상태 글은 작게 아래에 남긴다. 백엔드를 못 띄우면 오류를 그대로 보인다.
- **멀리·아이콘 얼굴.**
  - 흐리게(opacity, 필터) 보이는 방식을 다시 디자인한다. 이름과 로고가 또렷하고, 상태는 테두리·점 색으로 분명하다.
  - 쉬는 노드를 덜 눈에 띄게 하려면 바탕과 테두리 명도로 한다. 전체를 흐리게 하지 않는다. 잠든 노드(달)와 구분한다.
  - P11 목업(`app/design/board-mock/`)의 톤을 따른다. 바꾸기 전·뒤 스크린숏을 남긴다.
- **색.**
  - 캔버스 바탕(`--canvas`)은 검정에 더 가깝게, 점 격자는 그에 맞게 조절한다.
  - 콘솔 바탕·머리(`--con-*`, `--term-bg`)는 살짝 어둡게 한다. 터미널 글 대비는 지킨다.
  - 패널, 알약 등 다른 색은 그대로 둔다.
- **명령 입력.** 맨 아래 입력의 너비를 넓힌다. 예: 화면 너비의 50~60%, 최소·최대를 정하고 칩 줄과 가운데를 맞춘다. 줌 알약, 레일과 겹치지 않게 한다.
- **Delete 두 번.**
  - 고른 세션에서 Delete를 눌러 닫기 확인(보관·삭제·취소)이 뜬 상태에서 한 번 더 Delete를 누르면 "삭제"를 고른다. 바로 지우지 않고, 삭제 단추에 초점과 표시가 가며 Enter로 확정한다.
  - Esc는 취소다. 여럿을 고른 확인창도 같다.
- **설정 창.**
  - 스크롤 없이 한 화면에 들어가게 탭으로 나눈다. 예: 일반(언어, 트레이), 새 세션(Claude·Codex·DeepSeek 기본값), 잠재우기, 가지 펼치기, 보관과 리포 찾기.
  - 줄마다 이름·값·풀이가 정렬되게 다시 짠다. 체크 상자가 한 줄 가운데에 따로 놓이는 문제를 고친다.
  - 아래 텍스트 로고는 뺀다.
  - 창 크기(최소 크기 포함)에서 스크롤이 생기지 않는지 본다. 두 언어 모두 본다.

### 계획과 다른 곳

- 설정 탭은 지시의 예(다섯)보다 하나 많은 여섯이다. "새 세션"을 한 탭에 두면 최소 창(900×600)에서 DeepSeek 줄이 잘려 Claude Code와 Codex · DeepSeek로 나눴다.

- 처음 화면의 최소 2초는 처음 화면이 뜬 때부터 센다. 창은 글꼴 읽기(최대 1.5초) 뒤에 그리므로 창이 뜬 때부터는 조금 더 길다.
- 멀리 얼굴의 생김새를 보는 장면은 실제 claude 세션이 아니라 셸 노드에 상태를 창 안에서만 덮어 그렸다.

### 알려진 문제

- 설정 화면을 여는 옛 창 시험 `p12-quick.mjs`(새 세션 기본값), `p25-deepseek.mjs`(DeepSeek 칸), `p8-k4.mjs`(가지 펼치기 상한), `p16-lang.mjs`(설정 스크린숏)는 이제 해당 탭을 먼저 눌러야 칸이 보인다. 고치지 않았다(`[data-tab=spawn]`, `agents`, `branch`를 누르면 된다). `data-role`과 `data-field`는 그대로다.
- 처음 화면 덮개는 누르기를 막지 않아, 판을 이미 받았으면 덮개가 사라지기 전(최대 약 0.7초) 누른 곳이 뒤의 판에 간다.
- 쉬는 노드(30분)와 보통 준비 노드의 차이는 바탕·테두리 명도뿐이라 멀리서는 작다(`p28-02-far.png`의 a4). 더 드러내려면 `--con-idle-*` 값을 조절한다.
