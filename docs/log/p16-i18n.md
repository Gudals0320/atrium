### 완료 기준

1. 기본(영어)과 한국어로 같은 판을 찍어 둘을 견준다.
   - 찍는 화면: 판 전체, 아래 바, 승인 줄이 뜬 콘솔, 설정, 사이드바(보관함, missed 함), 새 세션 대화상자, 트레이 메뉴 글.

2. 설정에서 언어를 바꾸면 다시 읽지 않고 곧바로 바뀐다. 다시 켜도 고른 언어가 남는다. 새 판의 기본은 영어다.
3. renderer에 하드코딩 한글이 남지 않는다. 사전 파일과 주석, 사용자 내용 처리 코드는 뺀다. 확인 명령(`rg`)과 결과를 보고에 적는다.
4. 단위 시험(백엔드 170, 창 34)이 통과한다.
   - 사전 열쇠가 두 언어에 모두 있는지 보는 단위 시험을 더한다.
   - 기존 창 시험 가운데 글로 고르던 것은 고쳐 돌린다. 적어도 다음을 돌린다: `p11-turn.mjs`, `p12-quick.mjs`, `p13-convos.mjs`, `p15-close.mjs`, `p14-tray.mjs`.

### 알려진 문제와 번역하지 못한 백엔드 글

- 열쇠가 없는 백엔드 오류는 한국어 `message`가 그대로 보인다. 예: 없는 연결·덩어리·메모·칸반·턴, 설정 값 검사(`normalizePatch`), 하위 세션 명령 오류(`branch.mjs`, 주로 에이전트가 봄), `herdr_incompatible`, `needs_trust`, `moved`, '보낼 지시가 없다', 'all, folder, convos 중 하나가 필요하다'.
- 대화 묶임 글: 창이 `where`·`pid`로 다시 짓지만, 모르는 경우는 "May be bound · " 뒤에 진입점 이름을 그대로 보인다.
- 검색 결과의 빈 메모 이름 '(빈 메모)'(`search.mjs`), 다른 곳이 열 하나로 만든 칸반의 기본 제목 '체크리스트'(`kanban.mjs`), 루프 기록의 `history[].reason` 코드(영문 코드 그대로).
- 미션 맵 노드의 묻는 글(`n.ask`)은 에이전트가 쓴 내용이라 번역하지 않는다. 연결 선 글의 '띄움'(`links.mjs linkLabel`)은 창이 사전으로 바꿔 보인다.
- 영어 화면 한글 찾기는 판 상태와 사이드바 자료에 있는 한글 낱말을 사용자 내용으로 본다. 사용자 내용과 같은 낱말을 쓰는 화면 글은 놓칠 수 있다.
- 시험이 휴지통으로 보낸 것: p13-convos의 missed 고정 자료 복사본 9개, p15-close의 시험 대화 기록 1개.
- P18(이름 Atrium)과 겹칠 곳: 사전의 `app.name`('multitask')과 트레이 툴팁·확인창 제목이 그 열쇠를 쓴다. 화면 글 속 이름은 사전에서 바꾸면 된다.
