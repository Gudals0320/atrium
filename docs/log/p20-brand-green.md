## 지시

사용자 요청. 지휘 세션이 직접 고친다.

- 앱의 강조색을 모두 초록 톤(로고, 텍스트 로고와 비슷하게)으로 바꾼다. 지금은 주황이다.
- 텍스트 로고를 어디에 넣을지 정한다. 처음 화면을 만들지 정한다.
- 명령 입력 왼쪽의 네모 넷 아이콘을 Atrium 로고로 바꾼다.
- Claude Code 봇 아이콘을 모두 빼고 Claude 로고로 바꾼다. 왼쪽 레일의 세션 바로 띄우기 단추는 주황 바탕에 흰 심볼, 터미널 노드는 배경 없는 심볼(위키미디어 공용 `Claude_AI_symbol.svg`)이다.

사용자와 정한 것:
- 심볼 SVG를 내려받는다.
- 내 차례 표시는 주의색(주황)으로 남긴다.
- 텍스트 로고는 처음 화면과 설정 창 아래에 둔다.

완료 기준: 개발용 판의 창 시험으로 다음을 보고 스크린숏을 남긴다. 단위 시험과 빌드가 통과한다.
- 처음 화면
- 초록 강조와 주황 내 차례
- 명령 입력 로고
- 레일과 노드의 Claude 심볼
- 설정 아래 텍스트 로고

## 작업 기록

- 심볼은 `https://upload.wikimedia.org/wikipedia/commons/b/b0/Claude_AI_symbol.svg`(1,155바이트, 경로 하나, 스크립트 없음)를 받았다.
  - 노드용 `assets/kinds/claude.svg`는 받은 그대로다.
  - 레일용 `claude-badge.svg`는 같은 경로를 #D97757 둥근 네모 위에 흰색으로 얹었다.
  - 옛 봇 그림 `claude.png`, `claude-wait.png`는 지웠다.
  - 출처와 상표 고지는 `app/THIRD_PARTY_NOTICES.txt`에 적었다.
  - 빌드가 `dist/assets`를 지우고 다시 옮기도록 했다(지운 그림이 남지 않게).
- 강조 토큰(`tokens.css`):
  - `--accent`는 #1CB66D, `--accent-2`는 #75EC9C. 꽉 찬 단추 글은 어두운 색이다.
  - 일하는 중 테두리, 상태 색, 띄움 선, 칩 테두리, 터미널 커서, 지금 워크스페이스 탭(`--accent-tab*`, 옛 `--accent-brown*`)을 초록으로 바꿨다.
  - 내 차례 자리는 새 토큰 `--attn*`(옛 주황)으로 옮겼다: 내 차례 알약·목록·배지, 노드 테두리·빛·말풍선, 상태 알약, 승인 줄, 미션 맵, 사이드바.
- Atrium 로고:
  - `app/design/brand`의 `atrium-icon.svg`와 투명 `atrium-wordmark.png`를 `assets/brand/`로 복사했다.
  - 명령 입력 마크, 처음 화면(판을 받기 전: 로고, 텍스트 로고, 연결 상태), 설정 창 아래에 쓴다.
- 개발용 판 `atrium-dev-p20`(포트 47836)에서 `app/test/e2e/p20-brand.mjs`를 돌렸다.
  - 첫 실행에서 승인 줄 바탕과 글이 초록으로 나와, 승인 줄도 `--attn`으로 고쳤다.
  - 끝난 뒤 시험 세션, 백엔드, herdr 서버와 세션, 시험 폴더, 대화 기록을 지웠다.

- 사용자 피드백: 왼쪽 레일의 손으로 잇기를 선택 바로 아래로 옮겼다(서로 바뀌는 모드). 선택 도구의 커서는 꽉 찬 화살표로, 켜지면 초록 원 위에 검은색, 꺼지면 흰색이다.
