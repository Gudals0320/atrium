# E11. `--fork-session`은 첫 메시지 없이 갈래를 남기는가, 파일 복사로도 갈라 열 수 있는가

2026-11-02에 했다. 데스크톱 앱 세션을 판으로 가져오는 기능(갈라 열기)을 설계하기 전에 확인했다. 결론부터 적는다.

- **첫 메시지 없이 띄운 갈래는 남지 않는다.** `claude --resume <원본> --fork-session --session-id <새 ID>`로 띄우면 화면에는 원본 대화가 보이지만, 메시지를 보내기 전에는 새 ID의 대화 기록 파일이 생기지 않는다. 끝내도(Ctrl-C, 창 닫기) 생기지 않는다. 그래서 "갈라 열고 바로 잠재우기"는 할 수 없다.
- **메시지를 하나 보내면 갈래가 남는다.** 줄마다 `sessionId`는 새 ID로 바뀌고, 원본 메시지의 `uuid`는 그대로 남는다. 갈라졌다는 표시 필드는 없다. 원본 파일은 바뀌지 않는다.
- **파일 복사로도 갈라 열 수 있다.** 원본 대화 기록의 줄마다 `sessionId`만 새 ID로 바꿔 새 파일로 쓰면, `claude --resume <새 ID>`가 그 대화를 이어 간다. 프로세스와 모델 호출 없이 된다. 다만 Claude Code가 정한 방법이 아니라서 형식이 바뀌면 깨질 수 있다.
- **갈라 연 시점은 원본의 마지막 답 `uuid`로 적으면 된다.** 원본이 그 뒤로 이어진 만큼을 셀 수 있다.

## 1. 방법

| 항목 | 값 |
|---|---|
| Claude Code | 2.1.316, 모델 haiku |
| 폴더 | 새로 만든 시험 폴더 `C:\Workspace\atrium-fork-exp`. 끝난 뒤 그 폴더와 대화 기록 폴더(`~/.claude/projects/C--Workspace-atrium-fork-exp`)를 지웠다 |
| 원본 | `claude -p --session-id <A>`와 `--resume <A>`로 두 턴(답 ONE, TWO) |
| 갈래 | 대화형은 터미널 탭에서 띄웠다. 나머지는 `-p` |
| 지키는 것 | 실제 데스크톱 앱 세션과 기존 대화는 쓰지 않았다. 부모 세션의 Claude 환경 변수는 빼고 띄웠다 |

## 2. 결과

| 단계 | 결과 |
|---|---|
| 대화형 갈래, 메시지 없음(`--resume A --fork-session --session-id B`) | 화면에 두 턴이 보인다. 신뢰 확인은 뜨지 않았다(상위 폴더를 이미 신뢰). `~/.claude/sessions/<pid>.json`에는 `sessionId=B`가 있지만 `B.jsonl`은 없다. Ctrl-C 두 번(간격이 길어 끝나지 않음)과 탭 닫기 뒤에도 없다. 원본 `A.jsonl`은 크기가 그대로다 |
| `-p` 갈래와 메시지 한 턴(`--resume A --fork-session --session-id C`, 답 THREE) | `C.jsonl`이 생긴다. 52줄 모두 `sessionId=C`, 갈래의 `uuid` 32개 중 24개가 원본과 같고 원본의 마지막 답 `uuid`도 들어 있다. `fork`가 든 필드는 없다. `--resume C`에 "지금까지 답한 말"을 물으면 "ONE TWO THREE" |
| 파일 갈래(원본 43줄의 `sessionId`만 D로 바꿔 `D.jsonl`로 씀) | `--resume D`에 같은 질문을 하면 "ONE TWO". 원본은 그대로다 |
| 시점 세기(원본 마지막 답 `uuid`를 적고 원본을 한 턴 더 이어 감, 답 FOUR) | 적은 `uuid`를 원본에서 찾았고, 그 뒤 지시 1, 답 1을 셌다 |

## 3. 가져오기에 주는 뜻

- Claude Code의 `--fork-session`으로 한꺼번에 갈라 열려면 갈래마다 메시지 한 턴이 필요하다. 모델을 부르고 대화에 흔적이 남는다.
- 그래서 길은 둘이다.
  1. **처음 열 때 갈라 열기.** 가져올 때는 장부와 노드만 만들고, 사람이 처음 열 때 `--fork-session`으로 띄운다. 첫 지시가 갈래를 남긴다. 시점은 그때의 원본 마지막 답이다.
  2. **파일 갈래.** 가져올 때 판이 원본을 새 ID로 복사한다. 99개도 바로 끝나고, 열 때는 `--resume <새 ID>`다. Claude Code의 기록 형식에 기대므로, 깨지면 1로 돌아간다.
- 어느 쪽이든 원본 파일은 읽기만 한다. 장부에는 원본 대화 ID, 갈라 연 시점(원본 마지막 답 `uuid`, 시각), 새 대화 ID를 적는다.
