# Atrium 계획

## 지금: 바뀐 화면으로 실제 판 쓰기

사용자가 실제 판을 쓰며 피드백을 주고, 피드백마다 작은 작업으로 고친다.

- 실제 판을 쓰며 나오는 화면과 사용성 피드백을 고친다. 새 화면은 목업에 먼저 그리고 견준 뒤 옮긴다(`docs/research/board-mock.md` 4절).
- 화면 구조가 바뀌어 아직 다시 돌리지 않은 옛 창 시험(`p5-g4.mjs`, `c345.mjs`, `c3-trust.mjs`, `p6c-arrange.mjs`)을 맞춘다. 응답 필요 줄은 펼침 목록 안에 있고, 영역 이름표의 단추는 마우스를 올려야 보인다(`docs/testing.md`).
- 목업에 아직 없는 화면(오케스트레이터 카드, 먼 배율의 작은 콘솔)은 피드백에 따라 그린다.

## 열린 결정

- 패널 안에서 herdr로 나눈 패널의 `herdr`도 판 서버 것으로 맞출지.
- 판이 띄우지 않은 에이전트(ARCH 4절 F3)에도 hook을 붙일지. 붙이려면 그 에이전트를 띄우는 세션이 판의 설정 파일을 써야 한다. 지금은 그런 에이전트나 Claude Code가 아닌 종류가 일을 시키면 선이 생기지 않는다.
- 판에 올린 에이전트를 정식 하위 세션(ARCH 4절 K)으로 바꿔 줄지.
- `herdr agent prompt|wait|read`의 자동 승인을 자기 하위 세션으로만 좁힐지(herdr를 감싼 판 명령으로 바꾸기). 지금은 같은 판의 모든 에이전트에 묻지 않는다(ARCH 4절 K2).
- 일이 끝난 하위 세션을 부모가 끌지 둘지(지금은 둔다).
- 워크트리 하위 세션의 이어 가기(`resume_argv`에 `--worktree`가 없다)와, 닫힌 하위 세션을 사이드바에서 다시 열 때 부모 관계를 되살릴지(ARCH 4절 K, J2).
- "herdr 명령 자동 승인"(새 세션 대화상자, 기본 꺼짐)의 규칙 범위. 지금은 `herdr`, `test`, `printf`, `echo`로 시작하는 명령이다. Claude Code는 `${…}`나 `$PWD` 같은 셸 확장이 든 명령은 규칙과 상관없이 묻는다.
- 관계를 언제 선으로, 언제 붙여 묶기로 보일지(ARCH 4절 H5). 지금은 herdr에서 실제로 나뉜 패널만 처음부터 붙인다. P6a 작업자는 "나뉜 패널은 늘 붙이고, 서로만 주고받는 쌍은 붙이기를 제안만 하고, 역할·시킴·띄움은 선으로"를 제안했다.
- P6 피드백으로 정할 것: 크기를 키워 겹칠 때 막을지, 들어가며 친 한글 조합, 메모·칸반 소속 거리(120), 체크리스트 끝 표시를 칸으로 둘지, 루프를 한곳에서 보는 목록과 고치기, 출력 보기 창 모양(떠 있는 창, 전체 화면), Thread를 늘 펼칠지, 판이 띄운 셸이 herdr 재시작으로 없어지면 되살릴지, 셸로 돌아간 판에 올린 에이전트의 이름.
- `@all`의 범위. 지금은 캔버스 전체다(ARCH 4절 H8). 워크스페이스 하나에만 보내는 방법이 창에도 필요한지 써 보고 정한다.
- 워크스페이스 단추의 순서를 사람이 끌어 바꾸게 할지, 오래 빈 워크스페이스를 저절로 접을지(ARCH 4절 G1).
- 다른 저장소로 `cd`한 에이전트가 나눈 패널을 패널 폴더의 워크스페이스에 둘지, 부모의 워크스페이스에 둘지. 지금은 패널 폴더다.
- 검색이 대화 기록 파일 전체까지 뒤질지(ARCH 4절 H2). 지금은 판 기록만 찾는다.
- 루프의 "목표 달성"을 에이전트 판정이나 명령 성공으로까지 넓힐지(ARCH 4절 I5). 지금은 답 속 글로만 본다.
- 닫힌 세션을 판 기록에 얼마나 오래 둘지, 판 밖 대화 목록을 얼마나 옛것까지 보일지(ARCH 4절 J2·J3). 지금은 워크스페이스마다 칸별 300개를 창에 보낸다.
- 판 밖 대화를 판으로 열 때 모델과 권한 모드(지금은 판의 기본, 권한 `manual`). 원래 대화의 모델을 따를지(ARCH 4절 J4).
- 다른 종류(codex)를 herdr 재시작 뒤 닫힘으로 둘지, 그 하네스의 이어 가기 명령을 판이 만들지(ARCH 4절 J1).
- 조용함 표시의 기준 시간(ARCH 3절).
- 신뢰 대화상자 카드에서 사용자가 직접 "신뢰"를 누르게 할지. 넣는다면 키는 `down`, `enter`다(E1, E10). 지금은 "터미널에서 답하기"로 보낸다.
- 노드 터미널에서 한글을 조합하는 중에 Enter를 누르면 어떻게 할지. Claude Code 입력칸에서 Enter는 제출이다. 실제 IME 점검(E6 4절 4번) 결과를 보고 정한다.
- 명령 바에서 보낸 긴 지시(4줄 이상이나 800자 초과)는 Claude Code가 붙여 넣은 자료(`<pasted_content>`)로 감싸 모델에 넘긴다(E3). 지금까지는 모델이 그 안의 지시를 따랐다. 영향이 보이면 짧은 지시 한 줄을 먼저 치고 긴 글을 붙이는 방식을 시험한다.
- aside(브라우저 에이전트)의 기록을 판에 붙일지, 언제 붙일지. 읽는 방법은 `docs/research/data-sources.md`에 있다.
